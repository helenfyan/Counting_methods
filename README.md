This is the README file for "Common census methods can lead to fundamentally different ecological interpretations of coral reef fish communities" by Yan et al. This repository contains all the raw and 
formatted data in the /Data folder. The /R folder contains a source script (Source.R) containing custom functions used throughout the code, an analysis script (Analysis.R), which contains all the analyses
presented in the main and supplemental text, and a figures script (Figures.R), which generates all the figures presented in the main text.
